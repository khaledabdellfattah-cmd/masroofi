# مصروفي 💰

تطبيق شخصي لإدارة المرتب والمصاريف. بيشتغل على التليفون كتطبيق كامل، ومن غير نت، وكل بياناتك بتفضل على تليفونك بس: مفيش سيرفر ولا تسجيل دخول.

---

## 1) تشغيله على جهازك

محتاج يكون عندك [Node.js](https://nodejs.org) (نسخة 20 أو أحدث).

```bash
cd C:\Users\khale\Projects\masroofi
npm install
npm run dev
```

افتح الرابط اللي هيظهرلك (غالبًا `http://localhost:5173`). وعلشان تشوفه بمقاس الموبايل على الكمبيوتر: اضغط F12، وبعدين أيقونة الموبايل 📱.

**النسخة الحقيقية** (فيها الـoffline):
```bash
npm run build
npm run preview
```
وافتح `http://localhost:4173`.

**الاختبارات** (بتفتح التطبيق بمقاس 360×740 وتجرب كل حاجة لوحدها):
```bash
npm test
```

## 2) رفعه على النت (GitHub Pages) — مرة واحدة

1. اعمل حساب على [github.com](https://github.com) لو معندكش.
2. اعمل repo جديد: اضغط **New repository**، وسمّيه مثلًا `masroofi`، واختار **Public**، و**ماتعلّمش** على أي حاجة تانية (من غير README).
3. ارفع الكود. في الـterminal، جوه فولدر المشروع (حط اسم حسابك مكان `USERNAME`):
   ```bash
   git remote add origin https://github.com/USERNAME/masroofi.git
   git push -u origin main
   ```
   أول مرة، GitHub هيطلب منك تسجّل دخول في المتصفح.
4. في صفحة الـrepo روح **Settings ← Pages**، وتحت **Source** اختار **GitHub Actions**.
5. روح تبويب **Actions** واستنى العلامة الخضرا ✅ (حوالي دقيقة). لو ماشتغلش لوحده، افتح **Deploy to GitHub Pages** واضغط **Run workflow**.
6. التطبيق هيبقى على: `https://USERNAME.github.io/masroofi/`

**كل مرة بعد كده:** أي `git push` بيرفع النسخة الجديدة لوحده. وعلى التليفون، التحديث بيوصل في المرة التانية اللي تفتح فيها التطبيق.

> الكود هيبقى ظاهر للناس (ده شرط GitHub Pages المجاني)، بس **بياناتك نفسها مش في الكود**. هي على تليفونك بس.

## 3) تثبيته على التليفون

### أندرويد (Chrome)
1. افتح الرابط في **Chrome**.
2. اضغط ⋮ فوق، وبعدين **Add to Home screen** أو **Install app**.
3. هيظهر على الشاشة الرئيسية ويفتح كتطبيق عادي.

### آيفون (Safari)
1. افتح الرابط في **Safari** (لازم Safari بالذات).
2. اضغط زرار المشاركة ⬆️، وبعدين **Add to Home Screen**.
3. افتحه دايمًا من الأيقونة دي، مش من Safari.

> ⚠️ على الآيفون: لو فتحته من Safari العادي ومن غير تثبيت، ممكن iOS يمسح البيانات لو التطبيق ماتفتحش كام أسبوع. التثبيت على الشاشة الرئيسية بيحميها، والنسخة الاحتياطية (جاية في المرحلة 5) بتحميها أكتر.

## 4) استخدامه بسرعة
- **زرار + الكبير** تحت: اكتب المبلغ، اختار البند، واضغط حفظ.
- **مصاريف سريعة** في الرئيسية: لمسة واحدة وبتتسجل. ولو فيه حاجة بتكررها كتير، التطبيق هيقترحها بعلامة ＋.
- كل تسجيل أو حذف بيطلعلك زرار **تراجع** لكام ثانية.
- **السجل**: بحث وفلترة. دوس على أي مصروف علشان تعدّله أو تحذفه.
- **الإعدادات**: المرتب، ويوم القبض، والبنود، والمصاريف السريعة، والثيم.
